# First native human-agent table task

2026-10-02. This milestone connects the actual owned CEF catalog capture to a
native selected-field panel, the closed Rust proposal service and Codex 0.160.0
stdio App Server. The person selects fields and asks; the agent returns supplied
field IDs. The host copies their original values and provenance. **Use proposal**
revises the original unapproved draft and presents a fresh exact Review. **Save**
remains a separate native action.

The direct acceptance driver is `tests/native_agent_workflow.py`. Controlled
mode uses an original synthetic stdio process and cannot establish inference
availability. Default mode invokes the explicitly selected installed Codex with
the two synthetic Amber catalog fields only. Before Use and before Save, the
driver independently queries the actual SQLite store for zero rows/commits.
Proposal fields must equal the subset reconstructed from the original Review;
Use preserves the original draft/deadline and increments Review version. Durable
Review/batch/row equality and clean same-boot reopen complete the positive gate.

Separate controlled actual joins hold the peer after handoff for Stop, or before
handoff for control-helper death and native Quit. They require cleared native
source/task, real controller revocation, owned child absence and clean empty SQL.
Pre-export fault cases also require no received export. These invoke the same
native actions programmatically; they do not qualify physical OS input.

## Scope

Only the two owned catalog page patterns qualify native observation. This is a
field-selection extraction task, with no model-driven page actions. General-site
capture, learned page patterns, OS input, network observation/editing/interventions
and tracker alerts remain later work. The installed coding peer is trusted and
hosted inference may retain handed-off content; UI retirement cannot retract it.
No new runtime dependency, credential copy, keychain change or sudo was required.

Close joins an already pending owned Rust Stop, or uses its exact acknowledged
retirement if only helper reconciliation was pending. Wrong/missing Rust ACK
still fails closed and leaves shutdown honestly unclean. OS startup denials and
existing unexplained CEF startup/teardown failures remain unavailable
outcomes; successful serial cases do not establish concurrency or broad workload
qualification. Rust clock/write checks are conservative separate operations,
with the narrow suspension interval documented in its independent review.
