# Native source to reviewed fixture table

2026-10-02. This unit joins the owned root projection to the existing table
domain. The person must see the exact source beside normalized fields before
approval. It introduces no model, page mutation, input, export or network tool.
General observation remains disabled; the subsequent native UI still waits for
the independent control and measured capture-work gates.

One pure Foundation function accepts the native owned-fixture record and the
trusted controller run/origin. It produces one bounded six-column row with
schema/pattern versions. It does not reinterpret a URL as an origin or accept
failed, sensitive, opaque or incomplete root projection as a normal row.
The original source supplies all identity generations and capture interval.
All observed fields retain literal fragments and their non-actionable backend
node identity; absent/withheld fields have no fabricated node or fragment.
Child frames remain excluded and the batch remains partial.

Fixed reviewed schema: name is trimmed literal text; price explicitly requires
`USD n.nn`, preserving exact decimal digits without binary floating point;
two slash-separated valid USD alternatives are Ambiguous literal candidates.
Note is trimmed text (visible whitespace can normalize to Empty). SKU is
trimmed text; its covered-root absence is Missing. Quantity is a nonnegative
ASCII integer normalized by removing leading zeroes; other text is Invalid.
Private is always Inaccessible and its text is never copied. Other withheld
fields remain Inaccessible; withheld duplicate IDs do not invent candidates.
The native reader must have supplied exactly these six requested field IDs.

Foundation numbers are checked for integer type, positivity, range and boolean
confusion. Fields, fragments, identifiers and total serialized batch are bounded
to the controller contract. Source fragments, Value/Invalid literals and
Ambiguous candidates are independently checked by the eventual service.
No inferred currency, invented default, replacement value or missing-as-empty.

Direct red oracle: compile an entry implementation returning unavailable, then
pass native-shaped fixture records through the actual function and require
exact expected normalized states/literals/provenance. After implementation,
test all six states across ordinary/ambiguous cases, unknown currency, large
decimal preservation, hidden/private marker omission, wrong run/origin, stale
shape/booleans, duplicate/missing fields and invalid intervals. The probe is
test-only; actual CEF-to-database/UI integration remains a separate direct gate.
Independent code review follows green; no detsim or mutation work is introduced.
