# First joined native page/table workflow

2026-10-02. Join the reviewed CEF reader, pure native table projection and
closed Rust table service in the person-operated window. This implements the
plan's first useful page → source → review → saved table → clean reopen path.
The fixed selector proves that path before a model is necessary. Codex,
learned families, general observation and delegated OS/network effects retain
their later gates; an owned-fixture workflow does not satisfy those capabilities.

The original static catalog pages have no scripts, forms or external resources.
An owned loopback launcher supplies the exact origin, profile and database paths;
the native reader verifies live effective origin separately. Only the qualified
owned catalog workload enables Observe. The UI continues to label root-only
partial coverage and withheld children; general observation stays disabled.
Growing owned DOM/text/frame workloads, actual callback/UI latency, observed
memory and independent control handling must earn N3's recorded supported
workload before that capability is enabled. A callback byte limit or host
deadline cannot be presented as bounded renderer work.

Native controls show controller/control status, Observe, field/source review,
an explicit retention choice within the service's 24-hour source policy, Save
reviewed table, saved-table selection and Stop/Quit. Display semantic field
states beside their literal source fragments and capture identity/interval.
Source highlights are in the native captured-source view; old backend node IDs
never become current page geometry. Missing, inaccessible, invalid, ambiguous
and empty remain distinct. Exact source/retention details are available before
Save; the approval returns the immutable Review object received from the service,
never a reserialized display table or a shadow batch.

Observe produces a new native capture and the pure fixed-schema batch. Scope
and staging go through the closed service. Review returns exact content plus
its actual source expiry guard. A Save click approves that exact review and
commits its returned private-handle correlation identity; it does not approve
a different stage while either asynchronous step is pending. Changed selection,
retention or source retires that UI decision and requires a new review/version.
Current rows are shown saved only after acknowledged committed status and a
new guarded read. Admission/queued write is visibly pending, never durable success.

One UI epoch retires late callbacks after navigation, Stop, selection/review
replacement or disconnect. Controller request IDs, Stop generation and evidence
CommitIds remain their separate identities. Stop uses the urgent controller
channel and immediately requests the caller-owned native control fence; it
does not wait behind a slow clock/SQLite operation. Native control checks the
controller connection's worker-visible liveness independently of the CEF UI.
Neither native connection owns grants. Ordinary Stop preserves permitted staged
source/saved rows; a later human review may require an explicit staging revision
to retire the old approval. Unknown admitted outcomes are queried by identity
or fresh saved-list discovery, never retried under a new CommitId.

Review/read/list guards carry the actual boot and expiry deadline. Both the
native connection and UI compare a fresh actual witness before publication;
expiry/activation clears unavailable data. A fresh receive time cannot extend
retention. Saved rows reopen with their original identity/source rather than
being relabelled as a current browser capture. Missing legacy fragments or
intervals are labelled unavailable. Model/export uses remain absent.

Quit and last-browser close must drain a healthy table_close before shutdown
and CEF event-loop exit. Joining/reaping happens after the live loop ends;
no synchronous process/SQLite wait is added to AppKit. A bounded failure path
keeps dirty/unknown recovery visible rather than writing a clean marker or
purging automatically. No routine restart recreates an approval or retries a
commit. Browser profile and managed table recovery remain separate.

Direct acceptance uses actual CEF catalog fields, exact native projection,
actual child protocol and independent SQLite rows/review/dirty state. Exercise
Amber's ordinary states and Birch's ambiguous price; reject hidden marker
publication; Stop during queued work; duplicate identity; changed retention;
clean native close and same-boot restart of the same DB. Native UI smoke invokes
the same action methods as the human controls, with fixture-only stage hooks;
an operator can then try the documented launcher and visible window. Native
connection/authority fault oracles remain independently owned and reviewed.
No synthetic input posting or model is required for this first join.

Root owns main AppKit/CEF integration, fixtures, packaging and joined oracle.
Native table/control connections own their private supervision/decoding units;
the Rust service owns admission and durable lifecycle. Every implementation
unit receives direct red/green evidence and independent review before promotion.
