# Native tandem controls and closed controller transport

2026-10-02. Root-owned join after the lifecycle unit and reviewed Rust proposal/
export unit. This implements the useful task in native-tandem.md without expanding
the browser reader or permitting agent effects. Wire names and exact shapes will
follow the reviewed Rust unit contract before implementation.

The existing deterministic native controls remain the capture/source/review/Save
surface. Add a separate compact native agent panel so the already-qualified source
and exact Review views remain usable. The person chooses captured fields using
native controls, sees what is shared and the selected Codex role/model/account,
enters an objective and clicks Ask. Source selection comes from the actual retained
native table, with its original provenance and actual publication guard. Missing
or inaccessible fields remain explicit; hidden fragments cannot be reconstructed.
An unconfigured or unavailable agent leaves the deterministic path usable.

The app accepts trusted startup configuration for the installed Codex executable,
its selected environment and model. Provider configuration is not accepted from
page text, proposal output or arbitrary raw RPC. The controller owns agent spawn,
handshake, scoped handoff, final correlation, cancellation and reap. Extend the
existing native table connection with named closed agent operations, strict nested
reply validation and main publication checks; its ordinary and urgent slots stay
bounded. Starting inference returns an immediate task identity; status polling
never waits through a model turn inside the native two-second response budget.

Only a complete validated proposal is shown. The host has already reconstructed
its fields from supplied candidate IDs; streamed text and explanations do not
become extraction values. A separate Use proposal action stages that reconstructed
batch, retires the old decision and requires a new exact Review. Save remains a
human action in the original panel. No match is actionable discussion rather than
an empty successful table or automatic retry.

Navigation, activation, selected-browser close, Stop, expiry, disconnect and changed
projection retire pending agent publication. Data retirement must also revoke any
unsent provider projection at the controller's authority boundary; a UI epoch alone
cannot retract queued bytes. Already handed-off content is visibly potentially
disclosed. No resume/history reconstruction, provider fallback or late-result reuse
is implemented in this slice. Finite task/display queues and polling completion
return a truthful unavailable/cancelled state without silently spawning a new turn.

Direct acceptance will exercise these same native action methods against a
controlled actual child using the production decoder, then the installed Codex
on synthetic selected catalog fields. Inspect actual transmitted projection,
excluded marker absence, original guard/identity, final grounding, zero pre-Save
SQL rows, exact reviewed Save and clean reopen. Invalid, late and retired proposals
must not restore approval or write rows. Source review follows construction and
focused actual oracles; changes in native units receive their own direct tests.
