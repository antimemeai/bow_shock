# First native human-agent tandem task

2026-10-02. The operator authorized the next milestone after the first actual
catalog capture/review/Save/reopen POC: native lifecycle hardening, bounded agent
proposals and an actual Codex stdio connection. This implements B1–B3's first
extraction slice. The fixed catalog support boundary remains in force.

## Useful outcome

The person observes an owned catalog page, selects the captured fields to share,
enters an extraction objective and explicitly asks the configured agent. The
agent returns grounded field selections or no match, with an explanation. The
host copies source-backed values from its retained native capture into a proposed
table. The person reviews its fields, literal sources, retention and exact Review,
then chooses Save. Model text cannot write rows, invent extracted values, navigate,
post input, compose/send network requests or change the connection configuration.
The existing deterministic workflow remains usable when the agent is unavailable.

## Ownership and order

1. Native lifecycle owner qualifies actual navigation, browser identity, activation,
   renderer failure and pending Stop paths before the new UI is joined. Root reviews
   those direct CEF/child/SQLite results; the scope of unexecuted paths stays explicit.
2. Codex protocol researcher reads the installed0.160.0 schemas and official docs,
   probes only bounded metadata/handshake first, and reviews the Rust owner's unit
   plan. Schema generation is local evidence, not a dependency or SDK adoption.
3. Rust controller owner adds one closed proposal/export/owned-child lifecycle.
   Controlled peer tests use the production admission and byte-handoff path before
   actual inference. Shared authority retires requests on Stop, revocation, expiry,
   disconnect and shutdown. Worker waits must not block authority processing.
4. Root extends the native closed transport and human controls after the unit wire
   is agreed and lifecycle edits return. An independent reviewer attacks the join.
5. Only after scoped export/decoding/source-grounding greens, run a real Codex turn
   on explicitly selected synthetic catalog data, then actual joined CEF/review/Save/
   SQLite/reopen checks. Document capability, account/model placement and limits.

Codex is an installed trusted coding peer, not a contained browser model. No new
SDK, provider, signing permission or OS privilege is proposed. Its selected
execution environment is separate from page evidence. Existing operator account
use is authorized for this integration; credentials stay in the installed runtime.
A metadata probe or model listing does not establish successful inference access.

## Narrow contract

Use private inherited stdio with installed-version handshake, a fresh host-created
thread per request, no history resume/fork/compaction and no automatic fallback.
The native caller approves an immutable bounded field projection before export;
unknown source/origin or stale data is withheld. Capture provenance and the
source's original continuous deadline survive selection. Partial/hidden/missing/
ambiguous/invalid states stay explicit; only the selected permitted fragments and
needed identifiers leave the host. Provider/account/model and request/connection/
Stop identities come from host state, not model claims.

One active task, bounded JSONL records and output/explanation, one final candidate,
finite owned child and response deadlines. Exact proposal shape and field candidate
IDs are closed; unknown/duplicate/nested malformed, stale and conflicting replies
produce no accepted proposal or SQL write. Streaming deltas never become table data.
A final selection can reference only supplied host candidate IDs; code reconstructs
the table from the retained projection. No model-supplied evaluator or generated
value is accepted.

Export authorization is rechecked at the last host-controlled byte handoff under
serialized revocation. Queued unsent data is discarded; already handed-off bytes
are potentially disclosed and cancellation cannot recall them. Scope changes
require a fresh thread. Runtime diagnostics are bounded and avoid observation,
credential and raw provider-history dumping. Child cancellation/close reports its
actual narrow effect and owned process cleanup; thread completion is not Save.

## Direct acceptance

Controlled actual peers inspect bytes received before/after revocation and across
reconnect; positive allowed projections succeed, excluded markers remain absent.
Malformed/oversized/duplicate/late finals and instruction-shaped page text exercise
the production decoder and actual zero SQL effects. Stop and child death retire
proposal authority independently of provider cancellation. The native UI rechecks
its actual publication guard and display epoch before presenting/using a proposal.
Actual final-item/turn identities must match a completed turn and the requested
output schema; metadata-only success is not the live inference oracle.

Finish with a real synthetic-catalog proposal, human-reviewable exact table,
explicit Save and independent SQLite content/clean reopen. Rust basic rigor and
focused native/process checks follow changed fault classes. Detsim, mutation and
heavier tiers remain deferred by the operator. The milestone leaves general capture,
OS input, network workbench and learned page-family rules at their later gates.
