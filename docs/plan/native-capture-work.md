# Owned capture workload qualification

2026-10-02. Measure the actual matched CEF snapshot reader before exposing the
first person-operated catalog workflow. The full general reader and current
coordinate/input gates remain unavailable. Fixed immutable local pages are a
narrow supported workload, rather than a claim of bounded Blink work on arbitrary
sites. The owned launcher supplies only the two reviewed catalog responses.

Use actual growing static trees (64, 1,024, 8,192 elements), growing text (512 KiB)
and eight/32 alternate-origin child frames. Stop growth at an observed configured
host or operational limit; do not retry an unresolved native capture. Compare
catalog fixtures against these boundary cases. Native reader remains one capture
at a time, with its existing host byte/node/field limits and three-second waiting
deadline. Neither discard nor timeout cancels Blink traversal/serialization.

The native workflow smoke starts a 10 ms AppKit callback probe around the actual
reader transaction and schedules the same Stop action used by the human button
20 ms after capture begins. Record actual continuous times for requested Stop,
handler entry, Rust ACK and helper fence ACK. The independent control helper and
Rust authority connection are active throughout. This measures servicing of the
actual human-control method, not a physical keyboard shortcut/listener or OS
effect drain. There are no OS input effects in this POC. Main-loop delay and
Stop ACK must meet the plan's chosen 100 ms target for the supported catalog;
oversized workloads may withhold their records and are never enabled as a general
reader merely because Stop passes.

The independent Python driver samples actual app/helper RSS while each owned
process is alive and records callback result/capture interval/reasons, elapsed
time and process cleanup. RSS is an observed process peak, not a hard allocation
bound or worker-only measurement. The projection worker has its reviewed byte/
node/work limits, while engine work remains measured. UI capability wording and
the experiment record explicitly name the qualified workload and unavailable
general capture/input capabilities. The actual CEF-to-SQLite join remains a
separate oracle.

Root owns the minimal smoke instrumentation/driver and the supported-mode
integration. Independent native workflow review attacks enablement, late data,
Stop and clean-close paths. No model, fake clock, synthetic input posting,
network interference, new package or downloaded reference execution is added.
