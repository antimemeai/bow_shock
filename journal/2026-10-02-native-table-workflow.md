The root lane is joining the reviewed original reader and pure fixed-schema
projection to the closed Rust table child and independent native control helper.
The subplan is `docs/plan/native-table-workflow.md`; native connection owners
remain responsible for their private framing/supervision units. The unit has
not yet passed its actual joined oracle or independent review.

Wrote an original immutable loopback catalog service and operator launcher using
only Python's standard library, with exact routes and no file serving. Terminal
Ctrl-C does not kill the child before its native clean table-close workflow. The
first actual CEF red (`context/runtime/native-table-workflow-red.log`) loaded
Amber, observed its title/status and shut down the existing bootstrap shell,
then failed the expected missing `table_workflow` assertion. No surrogate DB
or fake native clock supplied this red.

Implemented native AppKit controls for six semantic field states, captured
literal source/identity, explicit retention and the exact immutable Review,
approval/commit followed by committed status and a guarded read. Selection,
navigation, Stop and expiry retire publication epochs. Saved identity never
becomes current-page geometry. Refresh discovers acknowledged saved results;
Delete immediately retires local display. Last-browser close retains the live
CEF event loop for `table_close`/shutdown, then owned reap occurs after the loop.
Failed close remains visibly dirty/unknown rather than claiming clean recovery.
