Important mechanism findings:

- `isTrusted` signifies UA dispatch, not proof of a real person.
- Quartz software posting does not imply a physical HID device. Posting and
  listening access checks are separate in installed MacOSX15.5 SDK `CGEvent.h`.
  Apple DocC confirms accessibility prompting is asynchronous.
- libei permits normal client-visible input while retaining compositor distinction
  and access control. InputCapture redirects active input; it is not passive
  global takeover monitoring. RemoteDesktop parent-window association is not
  evidence of window-confined authority.
- Current Chromium uses `network_change_notifier_apple.mm`; old Mac filename is
  absent. Feature-controlled Network.framework monitoring coexists with legacy
  SCReachability/DynamicStore paths. Linux current source adds feature-controlled
  XDG network portal online-state alongside netlink. The chosen engine revision
  and feature state matter.
- Packet impairment, route loss, address removal and link loss are different.
  Packet loss alone does not guarantee page offline events. External intervention
  and privacy effectiveness need different direct measurements.
- Movement and pauses depend on task, device, geometry, sequence and interruption
  state. The literature does not warrant universal coefficients or independent
  event jitter as a complete human model.
